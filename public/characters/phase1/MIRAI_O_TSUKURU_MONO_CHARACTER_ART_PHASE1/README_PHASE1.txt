MIRAI O TSUKURU MONO — OFFICIAL 93-CHARACTER ART PACK (PHASE 1)
================================================================

This archive is built from the user's uploaded 16-page / 93-number character roster.
It contains all 93 numbered entries as individual image crops, grouped by the page
categories in the source sheet, plus a CSV index and the complete original sheet.

IMPORTANT STATUS
- The source image is a monochrome sketch roster. Individual crops are preserved
  as source-reference sketches; they have NOT been falsely represented as finished
  full-colour designs.
- Front / side / back turnarounds and custom colour designs are the next artwork
  production phase. They are not included in this first source-extraction archive.
- Duplicate roster appearances are preserved as separate numbered entries (for
  example Shin Takamori, Rosey Rina Kobayashi and Ryūjin appear more than once).
- The uploaded roster does not contain detailed environment reference images for
  every Part 1, Part 2 and Part 3 location. Location folders are reserved for
  verified artwork rather than invented scenes.

Folder categories follow the source sheet:
Main Characters; Takamori Family; Big Father's Family; Shin's Family; Small Father's
Family; Father's Sister's Family; Kobayashi Family; Childhood Friends; Family Friends;
School; College; NOVATECH Corporation; SUKA SRI Core Team; World Leaders & Global Figures;
Mentor & Mythical World; Syndicate — The Dark Shadow.
