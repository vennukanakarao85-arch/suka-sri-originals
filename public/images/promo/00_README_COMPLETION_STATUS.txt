MIRAI O TSUKURU MONO — MASTER COLLECTION PACKAGE
=================================================

This package consolidates the currently created deliverables for the user's
official 93-character manga roster.

Included:
1. Phase 1 ZIP: 93 numbered individual crops from the supplied official roster,
   grouped into the 16 categories shown on the source sheet, with CSV index.
2. Development Starter ZIP: Phase 1 references plus initial visual concept board.
3. Development Batch 02 ZIP: separated concept crops for the main trio, supporting
   cast groups, SUKA SRI Headquarters, and Part 1/2/3 location concepts.
4. Promotional visual-development boards.

IMPORTANT COMPLETION STATUS
---------------------------
This is a consolidated master package of work actually created so far.
It is NOT a claim that all 93 characters have finished custom full-colour portraits,
front/side/back turnarounds, expression sheets, or that all locations from all
three parts have been individually illustrated.

The supplied roster image remains the authoritative identity/name reference.
Generated concept boards are visual direction only; tiny text and incidental
details inside generated boards are not authoritative roster data.

Still outstanding for a genuinely complete production archive:
- 93 individually rendered full-colour character sheets.
- Front, side, and back turnaround for every character.
- Character expression/costume sheets.
- Verified location art for Parts 1, 2, and 3.
- SUKA SRI Headquarters angle set and Shin/Ryujin dedicated angle set.
- A finished 15-second intro video.
